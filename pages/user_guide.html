Mason Jar user guide

Import sections, preprocess, align to the Allen atlas, detect cells, and export counts or region images.

First launch

  • App data lives under ~/.masonjar (Windows: %USERPROFILE%\.masonjar): Python, models, embeddings, and logs.
  • If you already use Bell Jar (~/.belljar), Mason Jar can copy that environment on first launch so you do not re-download ~20 GB.

Projects

Prefer a .masonjar project bundle (New project). Mason Jar creates a folder such as Name_masonjar/ with a project file and a data/ tree.

Legacy Bell Jar folders still open, with a warning that some tools are limited. Use migrate-to-.masonjar when you need the full pipeline. Batch runs selected steps across multiple projects. Optional processing subset on the workspace hub limits later steps to selected sections.

Typical workflow

  1. New project — import from CZI (or existing section images).
  2. Image preprocessing — Max Projection, then optional Sharpen / Top-hat / BaSiC / tissue cleanup.
  3. Atlas alignment — Align Sections, then Viewer/Editor.
  4. Cell detection — Detection → Count → Collate.
  5. Exports — Isolate Regions and/or dual-channel ROI TIFs.

Image preprocessing

  • Max Projection — per-channel max from Z-stacks.
  • Sharpen / Top-hat — wizards with preview and resume.
  • BaSiCPy Shading Correction — uneven illumination per channel; Align warping still uses uncorrected DAPI.
  • Re-import from CZI — re-extract slices into the open project.
  • Tissue edge cleanup — guided mask edits for tissue boundaries.

Atlas alignment

  • Align Sections — Napari section-to-atlas alignment; Finish confirms before writing warped outputs.
  • Viewer/Editor — inspect and edit atlas annotations.
  • Parcellation (bulk) — helpers for many sections.

Cell detection

  • Cell Detection — models with QC / scout options.
  • Count Brain — quantify detections by region.
  • Collate Counts — combine count outputs.

Exports

  • Isolate Regions — region intensity / ROI pickles (enable DAPI for dual-channel export).
  • Export dual-channel ROI TIFs — ImageJ-friendly TIFs (ch1 DAPI, ch2 signal) from ROI .pkl files with dapi_roi.

Settings

Settings covers network, dialogs, and updates. Application log opens the log window for troubleshooting.
